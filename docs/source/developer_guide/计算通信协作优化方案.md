## 1. 最终边界

```text
vllm-ascend
  ├─ layer/shape/TP/M routing
  ├─ external OPP + ABI availability check
  ├─ torch thin adapter
  └─ dynamic ACLNN call
             |
             v
memfabric_matmul_allreduce custom OPP (.run)
  ├─ ACLNN two-phase facade
  ├─ persistent MemFabric runtime
  ├─ 8-core cooperative MatMul
  ├─ public signal/wait/quiet

```

vLLM 不再编译 `.asc`、不发现/链接 MemFabric headers/`libmf_smem.so`、不拥有 arena/credit/mail/protocol lifecycle。

## 3. 8-core MatMul + 单 signal owner

每个 communication batch 是一个 8-core cooperative MM：

```text
A [batch_m, 2048]
B [2048, 2048] (NZ, transpose)
        |
        | 8 AI Core explicit M partitions
        v
C_local [batch_m, 2048]
```

8 个 core 都参与 MM。每个 core 完成自己连续的 M 分区后 clean 对应输出并发布 generation-ready；core0 也完成自己的 MM，随后等待 8 个 ready，只由 core0 调用一次 public `smem_shm_sdma_signal()`。

## 4. lookahead=1 流水

当前已迁移的数据流保持 pre-migration v8：

```text
gate(wave)
P0
P1 -> W0 -> A0
P2 -> W1 -> A1
...
drain last wait/add
quiet()
ack()
```

目标 overlap：

```text
SDMA(n)   || MM(n+1)
SDMA(n+1) || wait/reduce(n)
```

`quiet()` 每 wave 一次，不放到 batch 热路径。

## 5. batch / arena / tail

```text
batch_m     = 256*q
batch_bytes = batch_m * 2048 * sizeof(FP16)
```

默认 q=2，即 `batch_m=512`、payload=2 MiB。2 MiB 是派生值，不是协议常量。

arena 按 row budget 固定，上限 8192 rows；q 改变只改变每 wave 的 batch 数，不按 q 成比例扩大 arena。tail 使用一个 `batch_m` scratch：zero-pad + valid-row D2D copy，MM/SDMA 仍传完整 batch，reduce 只写 valid rows。

## 6. 协议与正确性

- MemFabric 仅使用 public host API 和 device `signal/wait/quiet`；
- 每封 data mail 严格检查 `status/dst/len/imm`；
- fixed credit 仍按 wave；
- eager generation 从 `0x40000000` 单调递增，避免每 wave 清 32 KiB ready cells；
- Graph 使用稳定 generation，并在 capture 中保留必要 control reset；
- 任一 protocol/device failure 后 runtime poisoned，要求两个 TP worker 一起重启。

## 7. Graph / lifecycle

Graph capture 前必须已完成：

```text
context create
-> pool/arena geometry
-> scratch allocation
-> producer/wait/add/protocol binary warmup
-> initial credit/protocol init
```

capture 内禁止首次 create/malloc/host barrier/lazy warmup。Graph-used runtime 保持 process lifetime。

因此 Graph 实机测试必须保持：

```text
VLLM_ASCEND_310P_MEMFABRIC_O_PROJ_WARMUP_FALLBACK=0
```

并在 capture 前确认至少一次真实 fused eager 调用成功。

## 8. vLLM routing

只有同时满足以下条件才关闭 generic TP reduction：

- feature enabled；
- external ACLNN symbols 可见且 runtime ABI=1；
- 310P3 / TP=2；
- Qwen full-attention `self_attn.o_proj`；
- local K=2048 / N=2048 / FP16 / unquantized NZ weight contract；
- M 达到配置阈值。

不满足则完整执行 stock MatMul + HCCL，不能出现“融合没调用但 `reduce_results=False`”状态。
