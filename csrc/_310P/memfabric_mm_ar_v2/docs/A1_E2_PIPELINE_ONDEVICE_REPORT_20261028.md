## 4. 结论与技术归因

1. **E2未达目标**：没有任何E2臂同时超过E1与Stock；E1仍是最佳融合候选。E2方向（放行树+READY预失效）作为性能杠杆**被实测否定**。
2. **E2-R≈E1（中性偏负）**：Core0串行1→7 IB放行不是E1的关键路径瓶颈；两级树反而为3/5/7核增加一跳中继。同步消息扇出优化到此为止。
3. **E2-P净负**：核首一次全8核ENTIRE缓存预失效+READY往返+额外ReleaseAdd的总成本，高于其省掉的每Chunk接收侧ENTIRE失效（M4096省3次/核仍输90µs），且引入最大507014暴露面。**READY栅栏预失效路线否定**。
4. **E2-P/512大幅负向**：分包翻倍（M4096为8×2MiB）与更多Chunk轮次的固定开销主导，重新证实F2结论——大M下Chunk1024优于512。
5. **长尾**：本轮各臂p99与p50成比例（Stock M2048首场有1332µs尾），未复现父分支D4式的周期性2372µs长尾；E2结构与长尾无正向关联。
6. **剩余差距**：E1对Stock仍差约148µs(M2048)/263µs(M4096)。结合父分支A1-MM-SHADOW证据（D4同构MM-only约848µs@M4096 vs NZ-MM 848µs相当、发送端CleanLines受控增量约140µs），**下一步最值得优化的关键路径是融合核内MM生产效率与producer侧每Chunk的ENTIRE失效成本、以及ReadyTree会合延迟**，而不是再加同步轮次或缩小分包；L1差距的主体在"同构MM+固定通信/同步税"，需要单变量内部分段设备计时才能精确拆分（`INNER_PHASE_UNKNOWN`仍成立）。
