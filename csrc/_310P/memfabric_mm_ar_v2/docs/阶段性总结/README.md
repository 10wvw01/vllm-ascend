## 归档原则

- **数据有出处**：引用源报告和代码；不将早期计划中的UNKNOWN误写成D4完成后的结果，也不把不同负载的性能混为一谈。
- **对比对象明确**：内部优化相对Tile1024，Stock基线相对原始MM+HCCL，端到端必须标注模型、负载和样本量。
- **风险随成果同行**：数值正确性、实际编译、稳定性、生产准入和后续阻塞必须分别披露。
- **范围不扩张**：本目录只总结融合算子及其薄接入，不恢复已废止的V2 Runner/DFlash重建任务。
